# 2026-herethon-3: 🏠 안심콕 (AnsimKok)
2026 여기톤 : HE:REthon 3팀

🔗 **배포 URL** : https://safetymap-ufnb.onrender.com/

혼자 사는 여성의 첫 시작, 안심콕과 함께하세요.

공공데이터와 실제 거주 여성들의 생생한 후기를 바탕으로, 지역별 안전 정보를 한눈에 제공하여 더 안전한 동네를 선택할 수 있도록 돕는 여성 맞춤형 주거 안전 정보 서비스입니다.

<br>

## 🔍 서비스 배경 (Background)

- 여성 1인 가구가 급증하고 있으나, 주거지 주변 방범시설 현황을 모른다는 응답이 36.2%에 달하는 등 실질적인 안전 정보 접근에 한계가 존재합니다.
- 여성은 주거지 결정 시 남성에 비해 '안전성(4.47/5점)'을 가장 중요한 요인으로 고려하며, 안전성 만족도가 높을수록 주거 만족도가 크게 증가합니다.
- 부동산 플랫폼, 지도, 공공데이터, 커뮤니티 등 여러 채널에 분산되어 있어 사용자가 직접 오가며 수집해야 했던 정보 탐색의 부담을 덜고자 기획되었습니다.

<br> 

## ✨ 핵심 기능 (Key Features)

### 1️⃣ 공공데이터 기반 안심지도 및 안심점수 (Ansim Map & Score)

- CCTV, 가로등, 파출소/지구대, 비상벨, 여성안심귀갓길, 범죄주의구간 등 공공 안전 데이터를 통합하여 100점 만점의 안심점수를 제공합니다.
- 지도의 색상 대비(진할수록 안전)를 통해 여러 지역의 안전 수준을 한눈에 직관적으로 비교할 수 있습니다.
- 원하는 안전 시설 필터를 선택하여 지도 위에 개수, 위치, 분포도를 즉시 확인할 수 있습니다.

### 2️⃣ 실거주 여성의 솔직한 후기 및 Q&A (Review & Q&A)

- 공공데이터 숫자만으로는 알기 어려운 밤길 분위기, 치안, 영역별 만족도 등 실거주자의 생생한 목소리를 전달합니다.
- 현재 위치 인증을 완료한 회원만 후기를 남길 수 있도록 설계하여 정보의 신뢰도를 보장합니다.
- 궁금한 점을 질문하고, 실제 동네 거주 경험이 있는 주민들로부터 직접 믿을 수 있는 답변을 받아볼 수 있습니다.

### 3️⃣ 추후 제공 예정 서비스

- **안심 귀가 서비스**: 실시간 동행 매칭, 경로 공유 및 위급상황 자동 알림 기능
- **안심 주거 서비스**: 안전한 전월세 계약 체크리스트, 이사 업체 추천 및 주거 가이드 연계

## 🚀 개발환경에서의 실행 방법

```bash
python -m venv myvenv
source myvenv/scripts/activate
pip install -r requirements.txt

# .env.example을 참고해 .env 파일 생성 후 API 키 입력
cp .env.example .env

python manage.py makemigrations
python manage.py migrate
python manage.py loaddata grids/fixtures/grid_fixture.json
python manage.py loaddata grids/fixtures/legal_dong_fixture.json
python manage.py loaddata grids/fixtures/district_fixture.json
python manage.py loaddata grids/fixtures/facility_fixture.json
python manage.py runserver
```
