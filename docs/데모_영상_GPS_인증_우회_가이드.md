# 데모 영상 촬영 시 실거주지 인증(GPS) 우회 방법

## 배경

실거주지 인증(마이페이지 > 실거주지 인증 > "현재 위치로 인증하기")은 브라우저의 `navigator.geolocation`으로 받은 실제 GPS 좌표를 서버로 보내서, 인증하려는 동(법정동) 경계 안에 있는지 확인하는 방식이다.

현재 시드 데이터에는 법정동이 **상계동(노원구)**, **신림동(관악구)** 두 곳만 있는데, 데모 영상을 촬영하는 사람이 실제로 그 동네에 있지 않을 가능성이 높다. 이 문서는 코드를 건드리지 않고 위치를 임시로 속이는 방법을 정리한 것이다.

## 방법: 크롬 개발자도구 Sensors 패널

앱이 위치를 받아오는 방식(`navigator.geolocation.getCurrentPosition`, `accounts/static/accounts/mypage.js`)은 브라우저가 넘겨주는 값을 그대로 쓰기 때문에, 크롬 개발자도구에서 위치 값 자체를 오버라이드하면 서버 코드를 하나도 안 바꿔도 원하는 동네에 있는 것처럼 인증할 수 있다.

### 단계

1. 촬영할 페이지를 크롬에서 열고 개발자도구를 연다. (Mac: `Cmd + Option + I`)
2. `Cmd + Shift + P`를 눌러 명령 팔레트를 열고 "Sensors"를 입력해서 **Sensors 패널**을 연다.
3. Sensors 패널의 **Location** 항목을 `No override`에서 `Other...`로 바꾸고, 아래 좌표 중 인증하려는 동네 좌표를 입력한다.
4. 마이페이지 > 실거주지 인증에서 "현재 위치로 인증하기" 버튼을 누르면, 실제 위치가 아니라 방금 입력한 좌표로 인증이 진행된다.
5. 촬영이 끝나면 Location을 다시 `No override`로 되돌려놓는다.

### 좌표 (시드 데이터 기준)

| 동네 | 위도 (Latitude) | 경도 (Longitude) |
|---|---|---|
| 상계동 (노원구) | 37.672991312700624 | 127.07035135198399 |
| 신림동 (관악구) | 37.46321719662122 | 126.93580201129161 |

## 배포된 사이트(Render)에서도 되는가?

된다. 이 방법은 브라우저가 페이지에 넘겨주는 위치 값 자체를 바꾸는 **클라이언트(브라우저) 쪽 기능**이라, 페이지가 로컬(`127.0.0.1:8000`)에서 열리든 Render에 배포된 실제 주소에서 열리든 동일하게 작동한다. 백엔드가 어디서 돌아가는지와는 무관하다.

오히려 배포 사이트는 HTTPS이기 때문에 위치 API를 쓰기에 더 안전한 조건이다. 로컬은 `127.0.0.1`이라 예외적으로 허용되는 것이고, 일반 HTTP 사이트였다면 위치 API 자체가 브라우저에서 차단된다.

## 주의사항

- 코드를 전혀 수정하지 않는 방법이라 커밋에 실수로 딸려갈 위험이 없다.
- Sensors의 위치 오버라이드는 해당 브라우저 탭/세션에만 적용되며, 다른 사람에게는 영향이 없다.
- 촬영 후에는 반드시 `No override`로 되돌려서, 이후 실제 테스트에서 혼동이 없도록 한다.
